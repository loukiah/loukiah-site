# loukiah.com

Website of Loukia Hadjiyianni, film director and photographer in Berlin.

- Built with [Eleventy](https://www.11ty.dev); published to GitHub Pages by `.github/workflows/deploy.yml` on every change.
- Edit texts, films and photos in [Pages CMS](https://app.pagescms.org) (settings in `.pages.yml`).
- Films: `src/films/*.md` · Texts: `src/_data/*.json` · Media: `src/media`.
- Photography page layout: `src/_includes/photo-field.html`.

Local preview: `npm install` then `npm start`.
